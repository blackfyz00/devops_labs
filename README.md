# Quotes Scraper Infrastructure

Асинхронный скрапер цитат с инфраструктурой на базе Terraform и локального облака Floci.

## Требования

-   Docker & Docker Compose
-   Terraform >= 1.0
-   Make

## Команды

### `make provision`
Разворачивает локальную инфраструктуру с чистого состояния:
1.  Запускает Floci (эмулятор AWS S3/SQS) через Docker Compose.
2.  Инициализирует и применяет Terraform-конфигурацию (`infra/`).
3.  Создаёт S3-бакет для результатов и SQS-очередь для заданий.

*Повторный запуск безопасен: Terraform не изменяет существующие ресурсы.*

### `make deploy`
Собирает и запускает контейнер со скрапером:
1.  Строит Docker-образ с Python, Playwright и Chromium.
2.  Получает имена ресурсов из `terraform output`.
3.  Запускает воркер с переменными окружения `SQS_QUEUE_URL`, `S3_BUCKET_NAME`, `AWS_ENDPOINT_URL`.

### `make run`
Отправляет одно тестовое задание в SQS-очередь:
-   Скрапер получает сообщение, собирает цитаты и сохраняет валидный JSON в S3.
-   Сообщение удаляется из очереди **только после** успешной записи в S3.

### `make destroy`
Полностью очищает окружение:
1.  Удаляет ресурсы Terraform (S3, SQS).
2.  Останавливает и удаляет Docker-контейнеры и volumes.

*Повторный запуск завершается без ошибок даже если ресурсы уже удалены.*

## CI

`make ci` выполняет проверки:
-   `terraform fmt -check` — форматирование HCL
-   `terraform validate` — валидность конфигурации
-   `pytest` — юнит-тесты
