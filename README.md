## 🚀 Быстрый старт

### Требования
- Docker & Docker Compose
- Terraform >= 1.0
- Python 3.12+ & UV

### Команды Makefile

| Команда | Описание |
|---------|----------|
| `make provision` | Запуск локального облака (Floci) и создание ресурсов (S3, SQS) через Terraform |
| `make deploy` | Сборка образа и запуск воркера скрапера в фоне |
| `make run` | Отправка тестового задания в очередь для проверки работы |
| `make destroy` | Полное удаление инфраструктуры и остановка контейнеров |
| `make clean` | Очистка локальных артефактов и образов |
| `make ci` | Локальная проверка форматирования TF и запуск тестов |

### Проверка результатов
После выполнения `make run` дождитесь обработки сообщения. Результаты появятся в S3 бакете.
